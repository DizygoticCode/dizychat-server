What is DizyChat?

Built by Dizygotic and Psybin, DizyChat is a focused, community-first chat stack that runs on lightning fast Socket.IO infrastructure. Rooms can stay public for casual hangouts or be locked down for trusted squads. You stay in control of your data while still enjoying all the goodies like search, pinning, soundboards, and live streams.

Simple instructions

Getting started takes under a minute. Follow the steps below any time you invite someone new to DizyChat.

1. Choose your name

Enter the alias you want everyone to see. You can change it next time you log in.

2. Pick a room

Join an existing room from the list or type a new name to create one. Add a password if you want it private.

3. Share the link

Once inside, copy the invite link from the toolbar to bring the rest of the squad.
